# Sales Data Analysis Using Python

## Project Overview

This project analyzes retail sales data using Python to identify sales trends, evaluate profitability, and discover business insights. The analysis helps understand product category performance, regional sales, and monthly sales trends.

## Objectives

- Analyze total sales and profit.
- Identify top-performing product categories.
- Compare sales across different regions.
- Analyze monthly sales trends.
- Identify the most profitable and least profitable categories.
- Create visualizations to communicate business insights.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses the Sample Superstore dataset, which contains retail order information, including sales, profit, product categories, regions, and order dates.

## Project Workflow

1. Import Python libraries.
2. Load the dataset.
3. Inspect and clean the data.
4. Perform exploratory data analysis (EDA).
5. Analyze sales and profitability.
6. Create charts and visualizations.
7. Generate business insights and recommendations.

## Key Analysis

- Total sales and total profit
- Sales by product category
- Sales by region
- Top 10 products by sales
- Monthly sales trends
- Profit margin by category

## How to Run the Project

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open Jupyter Notebook.
4. Open `notebooks/Sales_Data_Analysis.ipynb`.
5. Run the notebook cells in order.
